# Você Pode Curar Sua Vida — Landing page

Landing page estática, responsiva e em português para divulgação de *Você Pode Curar Sua Vida*, de Louise L. Hay.

## Publicação na Vercel
- Framework Preset: **Other**
- Root Directory: `./`
- Build Command: deixar vazio
- Output Directory: deixar vazio (site estático com `index.html` na raiz)

A Vercel pode publicar diretamente o projeto sem etapa de build.

## Arquivos
- `index.html`: conteúdo e estrutura da página
- `styles.css`: identidade visual e layout responsivo
- `script.js`: pequenos aprimoramentos de interface
- `assets/hero.svg`: ilustração vetorial original do site
- `assets/favicon.svg`: ícone do site

## Checkout
Os botões direcionam para o checkout fornecido: https://go.hotmart.com/V108487856C?dp=1

## Observações editoriais
A página não usa depoimentos inventados, não afirma que a obra cura doenças e orienta o visitante a consultar as condições comerciais diretamente no checkout da Hotmart. A obra é apresentada como leitura de autoconhecimento e desenvolvimento pessoal.
